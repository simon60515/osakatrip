加入手機主畫面

加了之後打開就像 App，不用每次找網址

  1. 用 Safari 打開這個網頁（不能用 Chrome）
  2. 點下方中間的 分享 ⎋ 按鈕
  3. 往下滑，找到 「加入主畫面」
  4. 右上角點 「新增」，桌面就多一個 icon

  4. 點 「新增」，桌面就多一個 icon
